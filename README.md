# Deep Patel, portfolio

Source for **https://deeppatel4000-pixel.github.io/**, the personal portfolio of
Deep Patel, a Class of 2027 student at Chelmsford High School planning to study
aerospace engineering.

- **Projects:** ORBIX, an aerospace engineering web app, and a rocket bell nozzle
  designed with NASA CEA, run through a CFD setup in SimFlow, and 3D-printed.
- **Experience:** youth leadership and service with BAPS, CNC fabrication at BAPS
  Akshardham, work, and school activities.

The site is plain HTML, CSS, and a small JavaScript file, published with GitHub
Pages from the `main` branch.
